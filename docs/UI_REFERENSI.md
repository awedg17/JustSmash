# Referensi UI JustSmash

2026-11-15 — usulan arah visual, belum disetujui/dipakai sebagai desain final. Screenshot terpublikasi diperiksa langsung; bukan gambar JustSmash dan bukan bukti interaksi atau animasi. Tidak ada aset referensi diimpor ke Unity.

## A. Nintendo Switch Sports — rekomendasi utama

![Menu Nintendo Switch Sports](https://www.gameuidatabase.com/uploads/Nintendo-Switch-Sports05062022-123307-51606.jpg)

Menu memperlihatkan tiga pilihan vertikal, turquoise terang, dan pilihan aktif dibedakan lewat ukuran, bingkai serta penanda. Ilustrasi olahraga berada di kanan.[1]

**Usulan adaptasi:** hierarki jelas dan label besar; identitas turquoise JustSmash tetap. Home cukup Main, Latihan, Pengaturan, Kredit. Hindari bentuk kapsul miring, logo, ilustrasi, dan komposisi persis sumber. Gambar konsol ini bukan bukti ergonomi sentuh Android.

## B. Roller Champions — alternatif sporty tegas

![Menu Roller Champions](https://interfaceingame.com/wp-content/uploads/roller-champions/roller-champions-main-menu.png)

Menu menempatkan aksi di kiri dan atlet tengah-kanan, dengan judul kapital tebal serta panel bersudut. Layar pemilihan mode menggunakan kartu besar; mode terkunci justru memperoleh sorotan kuat.[3][4]

**Usulan adaptasi:** kekuatan tipografi dan fokus atlet, bukan warna pink/grafiti/bentuk tiketnya. Main harus dominan; buang pola toko, battle pass, promosi dan undangan online. Tidak menambahkan fitur terkunci atau notifikasi demi dekorasi.

## C. Rocket League — alternatif arena sebagai latar

![Menu Rocket League](https://interfaceingame.com/wp-content/uploads/rocket-league/rocket-league-main-menu.jpg)

Menu memakai arena sebagai latar, navigasi kiri, subjek tengah dan panel berita kanan. Play disorot dalam menu, tetapi promosi kanan juga kuat.[7]

**Usulan adaptasi:** GOR dan atlet JustSmash menjadi latar Home. Menu ringkas; tanpa toko, berita atau party. Bukan menyalin panel biru, kendaraan, logo atau bentuk tombol.

## Rekomendasi, belum approval

A sebagai acuan keterbacaan. B hanya untuk ketegasan judul; C hanya untuk prinsip latar arena. Identitas tetap badminton/GOR lokal, bukan dashboard atau salinan game lain.

Setelah pemilik memilih arah, buat preview terpisah Home + Setup + HUD + Result sebelum redesign source. Pertahankan seluruh kontrol, setting, tunggal/ganda, dan aturan; lima shot + Lompat tidak dihapus demi tampilan. Target sentuh Android perlu validasi ukuran efektif di perangkat: tes sekarang mengukur unit canvas, **bukan membuktikan 48dp fisik**. Game tetap offline; Rp0; tidak memperoleh hak penggunaan aset dari keberadaan screenshot.

Scope career dicabut sesuai D-054. Penghapusan menu career adalah rollback fitur terpisah, bukan penerapan desain referensi ini. Gameplay/animasi/audio belum otomatis diterima karena referensi sudah dipilih.
